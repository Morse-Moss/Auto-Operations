# XHS 图片工坊草稿 AI 改图定稿设计

## 背景

草稿工坊可以把草稿素材送入图片工坊，图片工坊也可以基于参考图生成新图。但当前链路里，AI 生成图没有稳定进入草稿素材和最终发布资产生命周期，导致用户看到“生成成功”，送发布中心时却只能使用原帖子/原草稿图片。

本设计把小红书图片工坊定义为草稿发布前的图片定稿页：它不只是生成图片，而是决定哪些图片最终进入发布中心。

## 目标

- 从草稿工坊进入图片工坊后，稳定展示草稿候选图。
- 最终发布图支持多选、排序和移除。
- AI 改图生成后自动保存回当前草稿素材。
- AI 改图默认进入最终发布图队列。
- AI 改图会替换本次参考图的发布选择，但不删除原图。
- 送发布中心时只提交最终发布图队列，并保证队列图片是后端可发布路径。

## 非目标

- 不执行真实小红书发布。
- 不修改 XHS SDK、签名层或底层请求逻辑。
- 不扩展公众号图片工坊。
- 不做复杂图片编辑器、图层系统或历史版本管理。
- 不删除原图文件或历史 AI 图。
- 不做自动批量生成、高频请求或风控规避。

## 核心模型

### 候选图

候选图是可选池，不等于一定发布。候选图来源包括：

| 来源 | 标签 | 默认是否选中 | 说明 |
|---|---|---|---|
| 草稿素材 | 草稿素材 | 是 | 从草稿工坊带入的当前草稿图片。 |
| 原笔记案例图 | 原笔记案例图 | 否 | 只做参考候选，默认不发布。 |
| AI 改图 | AI 改图 | 是 | 图片工坊生成并回挂当前草稿的新图。 |
| 手动上传图 | 手动添加 | 是 | 用户在图片工坊上传的新图。 |

### 最终发布图

最终发布图是实际送入发布中心的唯一图片队列。

规则：

- 支持多选。
- 支持排序。
- 支持移除。
- 送发布中心时按当前顺序传递。
- 队列内图片必须是可发布路径：优先 `/api/files/media/...`，也允许系统当前已支持的外部 HTTP(S) 图片。
- 如果队列中存在不可发布路径，必须阻止送发布中心并提示用户处理。

### 草稿素材

草稿素材是跨页面、跨刷新可恢复的草稿图片事实源。

规则：

- AI 改图一旦进入最终发布图，必须自动保存回当前草稿素材。
- 保存成功后，刷新图片工坊或返回草稿工坊都应能看到这张 AI 改图。
- 清除图片工坊草稿关联不会删除已经保存到草稿素材的 AI 改图。

## 用户流程

### 1. 从草稿工坊进入图片工坊

草稿工坊保存当前草稿内容和素材上下文，然后进入图片工坊。

图片工坊顶部显示“来自草稿”卡片：

```text
来自草稿
草稿 #123 · 草稿名
标题：xxxx
正文摘要：xxxx

候选图 4 张 | 最终发布图 2 张

[✓] 图1  草稿素材
[✓] 图2  草稿素材
[ ] 图3  原笔记案例图
[✓] 图4  AI 改图

[全选草稿素材] [取消全选]
```

默认选择规则：

- 草稿素材默认全部进入最终发布图。
- 原笔记案例图默认不进入最终发布图。
- 如果恢复上下文时已有 AI 改图，它默认进入最终发布图。

### 2. AI 改图

用户选择参考图并点击生成。

生成成功后系统执行：

1. 获取生成结果的服务端媒体路径。
2. 将生成图新增为当前草稿的 `DraftAsset`。
3. 候选图区出现新图，标签显示“AI 改图”。
4. AI 改图自动加入最终发布图。
5. 自动取消所有本次参考图的发布选择。
6. 保留其他非本次参考图的已选发布图。

示例：

```text
生成前：
最终发布图：图1、图2、图3
参考图：图1、图2

生成后：
最终发布图：AI改图、图3
候选图：图1、图2、图3、AI改图
```

图1、图2 仍保留在候选图/草稿素材中，只是不再默认发布。用户可以手动重新勾选。

生成成功反馈：

```text
AI 改图已生成，并保存到当前草稿；已替换本次参考图的发布选择。
```

### 3. 手动上传图

用户上传图后：

1. 上传为后端媒体资产。
2. 加入候选图，标签显示“手动添加”。
3. 默认加入最终发布图。

### 4. 送入发布中心

用户点击“送入发布中心”时：

1. 校验最终发布图队列非空。
2. 校验每张图是可发布路径。
3. 按队列顺序传递 `asset_file_paths`。
4. 创建发布中心任务。
5. 跳转发布中心，但不自动真实发布。

## 页面结构

### 顶部：来自草稿

- 展示草稿标题、正文摘要、标签。
- 展示候选图数量和最终发布图数量。
- 候选图用 checkbox 多选。
- 点击图片或 checkbox 均可切换是否进入最终发布图。
- 提供“全选草稿素材”和“取消全选”。

### 中部：AI 图片生成

- 参考图来自当前选择的候选图或手动选择。
- 默认带入最多 2 张参考图。
- 生成按钮文案应体现当前任务是“生成 AI 改图”。
- 生成结果如果保存成功，自动回挂草稿并更新候选图/最终发布图。

### 下方：最终发布图片

- 展示已选择的最终发布图队列。
- 支持上移、下移、移除。
- 显示图片来源标签。
- 送发布中心按钮只使用此队列。

## 错误处理

### AI 生成成功但没有服务端媒体路径

不允许加入最终发布图，也不允许送发布中心。

提示：

```text
AI 图片已生成，但未保存为可发布素材，请重新生成并开启保存到资产。
```

### 回挂草稿失败

不自动加入最终发布图。

提示：

```text
AI 改图生成成功，但保存到草稿失败，已保留预览，请重试保存。
```

### 最终发布图包含不可发布路径

阻止送发布中心，并指出不可发布图片数量。

提示：

```text
有 1 张图片不是可发布素材，请重新保存、上传或移除后再送发布中心。
```

### 清除草稿关联

- 清空图片工坊中的草稿上下文。
- 清空最终发布图队列。
- 不删除已保存到草稿素材的 AI 改图。

## 数据流

### 草稿进入图片工坊

```text
DraftAsset / source note images
  → sessionStorage draft context
  → Image Studio draftContext
  → candidate_images
  → finalPublishImages
```

### AI 改图进入发布链路

```text
startImageGenerationTask(save_to_assets=true)
  → task result with asset.file_path
  → addDraftAsset(draft_id, local_path=fileName)
  → refresh/fetch draft assets
  → append AI 改图 candidate
  → remove reference image paths from finalPublishImages
  → add generated media path to finalPublishImages
  → sendDraftToPublish(asset_file_paths)
```

## 验证标准

- 从草稿工坊送入图片工坊后，候选图区稳定展示草稿图片。
- 草稿素材默认多选进入最终发布图。
- 原笔记案例图默认不进入最终发布图。
- AI 改图生成成功后自动保存回草稿素材。
- AI 改图显示为“AI 改图”。
- AI 改图自动进入最终发布图。
- 本次参考图自动从最终发布图取消选择。
- 非本次参考图的已选图片保持不变。
- 刷新后，已回挂草稿的 AI 改图不丢失。
- 队列里存在不可发布图片时，送发布中心被阻止。
- 送发布中心只创建待发布任务，不执行真实发布。
