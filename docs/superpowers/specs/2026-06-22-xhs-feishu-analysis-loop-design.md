# 小红书采集来源清晰化与飞书分析闭环设计

日期：2026-06-22

## 1. 背景

运营测试反馈集中在三类问题：

1. 数据采集入口看不出来源。运营需要直接区分“灰豚来的词”和“小红书站内来的内容”。
2. 过往抓取记录不可追溯。采集完成后，不清楚历史记录在哪里、入库结果在哪里、失败和跳过原因是什么。
3. 内容库缺少分析后的筛选和可视化能力。运营希望能按“产品/内容”等分析维度筛选，但当前阶段不应在系统内建设复杂产品管理、自动分类或标签体系。

结合桌面示例文件 `3A视频收集分析总表-拓效.xlsx`，当前最合适的设计是：

```text
系统负责采集、入库、同步和展示。
飞书多维表格作为外部分析数据库和协作分析中心。
飞书完成分析和打标签后，系统回传结构化字段用于内容库筛选和可视化。
```

## 2. 目标

第一版要完成三个闭环：

1. **采集来源清晰**：数据采集页按来源拆分为“灰豚热词采集”和“小红书站内采集”。
2. **采集记录可追溯**：运营能查看历史采集记录、入库数量、跳过/失败原因，并跳转查看本次入库内容。
3. **飞书分析回传可展示**：系统把小红书内容同步到固定飞书多维表格；飞书分析后，系统回传分析字段，在内容库中筛选、展示和后续生产。

## 3. 不做范围

第一版明确不做：

- 系统内产品管理。
- 系统内 AI 自动分类。
- 复杂规则引擎。
- 飞书文档解析。
- 图片/视频附件同步。
- 每次采集新建飞书表。
- 按批次新建飞书表。
- 完整操作审计历史。
- URL 抓取和账号主页抓取的新入口扩展。

## 4. 数据采集页改造

### 4.1 页面结构

左侧菜单继续保留一个入口：

```text
数据采集
```

页面内部拆成两个 Tab：

```text
灰豚热词采集
小红书站内采集
```

### 4.2 灰豚热词采集

定位：

```text
灰豚 = 热词/关键词来源，不直接进入内容库。
```

保留能力：

- 获取灰豚候选词。
- 手工导入灰豚热词。
- 导入关键词组。
- 最近灰豚热词记录。

### 4.3 小红书站内采集

定位：

```text
小红书 = 内容来源，采集结果可进入内容库。
```

第一版只展示当前已有两种方式：

- 按关键词组采集。
- 临时关键词搜索。

暂不扩展：

- URL 抓取。
- 账号主页抓取。

### 4.4 最近小红书采集记录

每条记录展示：

- 采集方式。
- 关键词或关键词组。
- 状态。
- 入库数量。
- 跳过数量。
- 失败数量。
- 采集时间。

支持动作：

- 展开跳过/失败原因。
- 查看本次入库内容。
- 同步本批次到飞书。

批次同步限制：

```text
如果本批次内容超过 100 条，不直接同步。
提示运营到内容库通过筛选或勾选分批同步。
不默认截断前 100 条。
```

## 5. 飞书作为分析中心

### 5.1 工作流

```text
小红书内容采集入库
  ↓
同步到固定飞书分析表
  ↓
飞书插件/运营做分析和打标签
  ↓
系统从飞书回传分析字段
  ↓
内容库展示、筛选、可视化
```

### 5.2 飞书集成入口

入口：

```text
全局设置 → 飞书集成
```

配置项：

- 飞书 App ID。
- 飞书 App Secret。
- 飞书多维表格地址。
- 目标数据表。
- 启用状态。

能力：

- 测试连接。
- 自动补字段。
- 查看最近同步状态。

安全要求：

- App Secret 加密保存。
- 不写入日志。
- 不进代码。

### 5.3 固定飞书分析表

第一版使用一张固定飞书分析表，类似“小红书内容分析总表”。

不按采集批次或关键词组新建表。批次、关键词组、来源等通过字段区分。

## 6. 飞书表字段设计

字段分为两组：系统同步字段和飞书分析字段。

### 6.1 系统同步字段

系统写入，飞书侧不建议手改：

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| 系统笔记ID | 文本/数字 | 系统 notes.id，回传匹配锚点 |
| 平台笔记ID | 文本 | 小红书 note_id |
| 采集批次ID | 文本/数字 | 对应采集任务或批次 |
| 数据来源 | 单选/文本 | 灰豚热词、小红书站内等 |
| 采集方式 | 单选/文本 | 关键词组采集、临时关键词搜索等 |
| 采集关键词 | 文本 | 搜索或命中的关键词 |
| 关键词组 | 文本 | 如果来自关键词组采集则写入 |
| 笔记标题 | 文本 | 小红书标题 |
| 笔记正文 | 文本 | 小红书正文 |
| 作者 | 文本 | 作者名 |
| 原链接 | URL/文本 | 小红书原链接 |
| 笔记类型 | 单选/文本 | 图文、视频、其他 |
| 标签/话题 | 文本 | 小红书标签和话题 |
| 点赞数 | 数字/文本 | 互动指标 |
| 收藏数 | 数字/文本 | 小红书重点指标 |
| 评论数 | 数字/文本 | 互动指标 |
| 分享数 | 数字/文本 | 如果可稳定获取则写入 |
| 采集时间 | 日期/文本 | 采集时间 |
| 同步时间 | 日期/文本 | 同步到飞书的时间 |

第一版不同步：

- 图片附件。
- 视频附件。
- 媒体完整性。
- 本地媒体路径。

原因：先打通飞书分析闭环，附件上传后置。

### 6.2 飞书分析字段

第一版使用小红书内容分析精简模板：

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| 分析状态 | 单选 | 待分析、分析中、已完成、废弃 |
| 产品/主题对象 | 文本 | 产品、服务、主题、问题或内容对象；不是系统产品管理 |
| 内容类型 | 单选 | 小红书内容形态 |
| 核心卖点/核心观点 | 文本 | 最值得复用的观点、卖点或表达 |
| 目标人群 | 文本 | 内容面向谁 |
| 封面/标题钩子 | 文本 | 用户为什么点进来 |
| 内容结构分析 | 文本 | 内容组织方式，如痛点 → 场景 → 解决方案 → CTA |
| 可复用模型 | 多选 | 可沉淀的内容打法 |
| 复用价值 | 单选 | 后续拿它做什么 |
| 分析备注 | 文本 | 飞书侧自由备注 |

## 7. 结构化选项

### 7.1 分析状态

- 待分析。
- 分析中。
- 已完成。
- 废弃。

同步新记录到飞书时默认：

```text
分析状态 = 待分析
```

已有记录再次同步时，不覆盖分析状态。

### 7.2 内容类型

- 种草。
- 测评。
- 避坑。
- 教程。
- 合集/清单。
- 对比。
- 痛点共鸣。
- 案例故事。

### 7.3 可复用模型

- 问题驱动模型。
- 情绪驱动模型。
- 场景种草模型。
- 对比反差模型。
- 测评背书模型。
- 教程方法模型。
- 故事案例模型。
- IP/热点借势模型。

### 7.4 复用价值

- 选题参考。
- 标题参考。
- 正文结构参考。
- 卖点表达参考。
- 可直接改写。
- 行业观察。
- 竞品参考。
- 废弃。

## 8. 同步策略

### 8.1 系统到飞书

触发位置：

- 采集记录：同步某个批次。
- 内容库：勾选内容同步。
- 内容库：当前筛选结果同步。

数量限制：

```text
最多 100 条/次。
超过则提示缩小筛选或分批处理。
不自动截断。
```

写入规则：

```text
新记录：
- 写入系统同步字段。
- 分析状态 = 待分析。
- 其他分析字段为空。

已有记录：
- 只更新系统同步字段。
- 不覆盖飞书分析字段。
```

幂等匹配顺序：

1. 飞书记录 ID。
2. 系统笔记 ID。
3. 平台笔记 ID。

### 8.2 飞书到系统

触发位置：

- 内容库：勾选内容回传。
- 内容库：当前筛选结果回传。
- 设置页：全量回传或维护。

数量限制：

```text
内容库局部回传最多 100 条/次。
设置页全量回传第一版可先同步已关联记录，后续可升级后台任务。
```

回传策略：

```text
飞书是分析字段事实源。
系统读取飞书分析字段，覆盖更新系统分析结果。
飞书字段清空，系统也同步清空。
```

回传所有分析状态：

- 待分析。
- 分析中。
- 已完成。
- 废弃。

`已回传` 不作为飞书分析状态，而是系统同步状态。

## 9. 系统数据模型建议

新增独立分析结果表，不污染 `notes` 原始模型。

建议表：

```text
note_analysis_results
```

建议字段：

- id。
- note_id。
- source，第一版固定为 feishu。
- external_record_id。
- analysis_status。
- subject_object。
- content_type。
- core_points。
- target_audience。
- title_hook。
- content_structure。
- reusable_models。
- reuse_value。
- analysis_note。
- last_pushed_at。
- last_pulled_at。
- push_status。
- pull_status。
- last_error。
- raw_payload。
- created_at。
- updated_at。

边界：

```text
notes = 原始采集事实源。
note_analysis_results = 飞书分析结果事实源镜像。
```

## 10. 内容库展示与筛选

### 10.1 筛选项

第一版筛选项：

- 关键词/搜索词。
- 飞书同步状态。
- 分析状态。
- 内容类型。
- 复用价值。
- 可复用模型。

### 10.2 搜索范围

关键词/搜索词搜索：

- 标题。
- 正文。
- 作者。
- 标签/话题。
- 采集关键词。

### 10.3 列表卡片

弱展示：

- 分析状态。
- 内容类型。
- 复用价值。
- 可复用模型。

不在卡片展示：

- 采集批次。
- 采集关键词。
- 完整分析备注。

### 10.4 详情页

展示完整分析字段：

- 产品/主题对象。
- 核心卖点/核心观点。
- 目标人群。
- 封面/标题钩子。
- 内容结构分析。
- 可复用模型。
- 复用价值。
- 分析备注。
- 飞书记录链接。
- 最近同步/回传状态。
- 失败原因。

### 10.5 废弃内容展示

如果飞书分析状态为 `废弃`：

- 系统正常展示。
- 列表和详情标记废弃。
- 筛选时可排除。
- 不自动删除。

## 11. API 草案

具体路径可在实施计划中调整，建议能力如下。

### 11.1 飞书配置

```text
GET /api/integrations/feishu/config
PUT /api/integrations/feishu/config
POST /api/integrations/feishu/test
POST /api/integrations/feishu/ensure-fields
```

### 11.2 推送到飞书

```text
POST /api/integrations/feishu/xhs-notes/push
```

请求支持：

- note_ids。
- task_id / batch_id。
- 当前筛选条件。

返回：

- created_count。
- updated_count。
- failed_count。
- skipped_count。
- errors。

### 11.3 从飞书回传

```text
POST /api/integrations/feishu/xhs-notes/pull
```

请求支持：

- note_ids。
- 当前筛选条件。
- all_linked。

返回：

- updated_count。
- missing_record_count。
- unmatched_count。
- failed_count。
- errors。

## 12. 验证标准

### 12.1 采集页

- 数据采集页有两个 Tab：灰豚热词采集、小红书站内采集。
- 灰豚能力不暗示直接进入内容库。
- 小红书站内采集显示历史记录。
- 历史记录可展开跳过/失败原因。
- 历史记录可跳转查看本次入库内容。

### 12.2 飞书集成

- 能保存飞书配置，密钥加密。
- 能测试连接。
- 能自动补齐目标表字段。
- 能把不超过 100 条内容同步到飞书。
- 已存在记录再次同步时，不覆盖分析字段。
- 新记录分析状态默认待分析。

### 12.3 回传

- 能从飞书读取分析字段并写入 `note_analysis_results`。
- 回传覆盖旧分析字段。
- 飞书字段清空时，系统对应字段也清空。
- 待分析、分析中、已完成、废弃均可回传。

### 12.4 内容库

- 可按飞书同步状态、分析状态、内容类型、复用价值、可复用模型筛选。
- 可搜索标题、正文、作者、标签/话题、采集关键词。
- 列表弱展示分析状态、内容类型、复用价值、可复用模型。
- 详情展示完整分析结果和同步/回传状态。
- 废弃内容正常显示但有明确标记。

## 13. 用户影响

- 运营不用再靠口头解释区分“灰豚”和“小红书”。
- 采集之后能看到历史记录、入库结果和异常原因。
- 飞书继续承担协作分析中心，不打断现有运营习惯。
- 系统不急着内建复杂分析体系，只把飞书结构化结果接回来做展示和筛选。
- 内容库从“素材堆”变成“已分析素材池”。
